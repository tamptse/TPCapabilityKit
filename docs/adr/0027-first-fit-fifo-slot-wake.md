# First-fit FIFO slot wake with skip

Release scans the arrival queue from the head and admits every waiter fitting the freed capacity in arrival order, bounded by that capacity; woken means admitted under the same lock and the batch resumes outside the lock. Supersedes the head-only wake half of ADR-0013: strict FIFO bought idle slots behind one blocked head while fitting demands waited, so throughput tracked the worst waiter instead of real contention. The head keeps priority as the first candidate on every scan and a skipped waiter loses no place, so skipping delays but never strands — an unfit head faces capacity exhaustion, not unfairness, and no overtake counter is introduced. Rejected: wake-then-contend (churns continuations for unreserved capacity) and relaxing the newcomer no-overtake rule (reopens queue-jumping through the other door).
